vulkan launcher - версия без установщика
========================================

Эта сборка сделана для старого компьютера: она не ставится в систему,
а просто лежит папкой и не содержит ни установщика, ни встроенного
браузера. Java уже внутри, доустанавливать ничего не нужно.


КАК ЗАПУСТИТЬ
-------------

1. Распакуйте архив ЦЕЛИКОМ в любую папку.
   Не запускайте файлы прямо из архива и не выдёргивайте их по одному:
   лаунчеру нужны все папки рядом.

2. Откройте файл «ЗАПУСТИТЬ.bat».

3. Само откроется окно браузера с интерфейсом - это и есть лаунчер.

Всё. Установка не требуется, в систему ничего не прописывается,
ярлыки не создаются, удалить лаунчер - значит просто удалить папку.


ВАЖНО ПРО ЧЁРНОЕ ОКНО
---------------------

Вместе с браузером внизу экрана появится свёрнутое чёрное окно.
Это работает сам лаунчер. Пока оно открыто - лаунчер жив, браузер можно
закрывать и открывать заново по адресу http://127.0.0.1:47820/

Закроете это окно - лаунчер выключится.

Если браузер не открылся или что-то не работает - разверните это окно
и посмотрите, что в нём написано. Текст ошибки оттуда и есть ответ.


ПОЧЕМУ ТАК
----------

Обычная сборка лаунчера несёт внутри Chromium - тот же движок, что в
Chrome. Он требует процессор с набором инструкций SSE3 и минимум
Windows 10, весит больше 200 МБ и ставится установщиком, который
некоторые антивирусы молча блокируют.

Здесь ничего этого нет: работает обычная Java, интерфейс открывается
в том браузере, который у вас уже есть. Весит вчетверо меньше.


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------

«Не найден рантайм» - архив распакован не целиком. Распакуйте заново
и проверьте, что рядом с «ЗАПУСТИТЬ.bat» лежат папки runtime-x64
и runtime-x86.

Браузер не открылся сам - откройте вручную: http://127.0.0.1:47820/

Окно браузера открылось, но список версий пустой - подождите, идёт
первый запуск: лаунчер поднимает игровые файлы. Это бывает долго
только в первый раз, дальше версия остаётся на месте.


ГДЕ ЛЕЖИТ ИГРА
--------------

Игровые файлы (сама игра, библиотеки, ресурсы) складываются в
%APPDATA%\pulsePLUS - отдельно от папки с лаунчером. Удаление папки
лаунчера игровые файлы не затронет.
