# vulkan launcher

Лаунчер Minecraft для Windows: изолированный Vanilla-профиль, управляемая совместимость
модов, вход через Microsoft и набор оптимизаций, чтобы игра шла и на слабом железе.

![иконка](installer/icon-vulkan.png)

## Возможности

**Два профиля, которые не мешают друг другу.** Режим `vulkan` — сборка с мод-клиентом,
режим `Vanilla` — чистый клиент. У каждого своя папка, свои моды и свои настройки,
файлы не пересекаются. Переключение одной кнопкой, фон и иконка окна меняются вместе с режимом.

**Аккаунты.** Офлайн-профили и вход через Microsoft по device-code flow
(Microsoft → Xbox Live → XSTS → Minecraft Services). Настоящий ник, скин и доступ
к онлайн-игре. Refresh-токен хранится локально, токен доступа живёт только в памяти.

**Моды.** Каталог Modrinth прямо в лаунчере, установка и удаление, проверка совместимости
с выбранной версией и загрузчиком, автоматическое отключение несовместимых
с сохранением состояния в профиле версии.

**Оптимизация.** Флаги JVM по набору Aikar против рывков, объём памяти подбирается
по машине, кнопка «Ускорить игру» ставит Sodium, Lithium, FerriteCore, ImmediatelyFast,
Krypton, EntityCulling и ModernFix одним нажатием.

**Оформление.** Тёмная тема со стеклом, волна по клику — настоящая симуляция волнового
уравнения, где элементы интерфейса задают более плотную среду, — и живой фон на кнопках:
луг в режиме Vanilla, небула в режиме vulkan.

## Установка

В релизе две сборки — выбери по разрядности своей Windows:

| Файл | Для чего |
|---|---|
| `vulkan-launcher-Setup-<версия>-x64.exe` | 64-битная Windows (обычный случай) |
| `vulkan-launcher-Setup-<версия>-x86/32.exe` | 32-битная Windows |

Права администратора не нужны. Лаунчер ставится в `%LOCALAPPDATA%\Programs\vulkan launcher` или на выбор польхователя.
и создаёт два ярлыка: обычный и `Vanilla`.

### Требования

**Java.** Лаунчер ищет её сам в Program Files или по `JAVA_HOME`. Нужна:

- **java 25** - для minecraft 26.## и выше.
- **Java 21** — для Minecraft 1.17.## и выше. Её требует сама игра.
- **Java 17** — для версий до 1.20.## включительно. Лаунчер возьмёт её, если 21-й нет.
- **java 8** - для версий до 1.17.##.

**Про 32-битную Windows** На ней лаунчер по архитектуре вашей сборки винды.

## Сборка

Нужен JDK 17+ (проект собран на Temurin 17).

```
./build.sh
```

Скрипт компилирует `src/src/main/java`, вшивает gson и упаковывает
`build/libs/vulkan-launcher.jar`. Проверено: классы, собранные им, побайтово совпадают
с классами боевой сборки.

установщик — `installer/dist/vulkan-launcher-Setup-<версия>-<арх>.exe`.
Перед сборкой в `installer/backend/` должны лежать `vulkan-launcher.jar`,
`pulsePLUS.jar` и папка `videos/` с фоновыми роликами: они не хранятся
в репозитории, а входят в релиз отдельными файлами.

Установщик кладёт приложение в `%LOCALAPPDATA%\Programs\vulkan launcher` (права
администратора не нужны). запрос идет только если само приложение подозревается фищингом microsoft defendr и создаёт два ярлыка: обычный и `Vanilla` с аргументом
`--mode=vanilla`.

## Где что лежит

```
src/src/main/java/launcher/
├── Main.java              точка входа, поднимает HTTP-сервер на порту 47820
├── auth/                  аккаунты и вход Microsoft
├── minecraft/             загрузка версий, загрузчиков, запуск игры, флаги JVM
├── mods/                  каталог, установка, состояние, набор производительности
├── music/                 музыка и bytebeat
├── catalog/               каталог версий и сборок
└── web/WebServer.java     HTTP-сервер, API и раздача интерфейса

src/src/main/resources/web/    интерфейс: HTML, CSS, JS
app/                           Electron-оболочка: окно, сплэш, запуск бэкенда
installer/                     проект electron-builder и скрипт иконок
design/                        заметки по анимациям
```

Данные лаунчера живут в `**выбор пользователя**`: конфиг, аккаунты, игровые профили,
моды, музыка, кэш.

## Заметки по реализации/не обязательно читать
**Волна по клику** — не «кружок из точки», а симуляция волнового уравнения на сетке
(клетка 5 px). Элементы интерфейса затираются в ту же сетку как более плотная среда:
волна проходит сквозь них, замедляясь и изламываясь, а не отбивается от стенки.
Рисуется не высота поля, а крутизна склона — у бегущей волны она максимальна ровно
на фронте, поэтому выходят тонкие кольца, а не мутные пятна.

**Фон на кнопках** — один общий холст переезжает в наведённую кнопку. У эффекта общие
часы, которые идут непрерывно: наведение только показывает анимацию на текущей фазе,
а не запускает её заново.

**Уровень производительности** определяется до первой отрисовки по числу ядер, объёму
памяти и строке видеокарты. На слабых машинах отключается `backdrop-filter`
(самый дорогой эффект интерфейса), паузится круг за курсором и волна считается
по более крупной сетке вдвое реже. Тени и объём остаются — уходит только цена.
